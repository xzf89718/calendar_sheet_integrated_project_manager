# weekreport_clean —— 周报清洗

把外部收集来的周报 Excel 清洗成可导入本框架的格式：日期按
**年月日三元组**匹配（横杠 / 斜杠 / 中文写法互通，"2026年10月20日"、
"2026/10/20"、"10-20" 都能认），清洗规则双表预览（原表 / 结果
对照），确认后写出。

本模块只有图形界面，无命令行入口。与主程序共享 fields.json。

## 运行

```bash
python weekreport_clean/clean_gui.py
```

## 工作流

1. 启动后选择要清洗的周报 xlsx
2. 左侧原表、右侧清洗结果，逐列对照
3. 确认无误后写出新文件
4. 回到主程序「导入」选通用模板导入

## 什么时候用

- 同事/客户交来的周报格式五花八门（日期写法、列名不统一），
  先过一遍清洗再进库
- 自己的历史 Excel 数据迁移进本框架前的预处理

数据唯一入口仍是主程序的「导入」；本模块只做格式清洗，不直接
写库。
